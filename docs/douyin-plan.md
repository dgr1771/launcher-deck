## 一、账号与内容定位（先想清楚再发）

**账号人设**：独立开发者「隔壁村布布」——一个人把一个桌面产品从 0 做到上架，全程真实、不装、有技术含量但说人话。

**内容主线**（这就是你的差异化）：
不做纯教程号（卷不过）、不做纯搞笑号（留不住技术粉），做 **"独立开发实录"**——把开发过程中真实的坑、翻车、修复、迭代拍出来。技术围观者爱看踩坑，普通人爱看"原来软件是这么做出来的"。

**爆款逻辑**：每一集 = 一个冲突（bug/翻车/较真）+ 一个解决 + 一个爽点（成品演示）。开发过程本身就是剧情。

**目标人群**：程序员/大学生/数码爱好者/软件折腾党 + 泛用户（被"把电脑变成塔罗牌"的视觉钩住）。

## 四、素材清单（已备好 + 需要你录的）

**已备好（`launcher-deck\docs\douyin-material\`）**：
- `01-玻璃主界面.png` 全景定妆照（E1 封面用这张）
- `02-少女心主题.png` / `03-豆沙绿主题.png`（E5 投票素材）
- `04-花色过滤.png`（E4）
- `toprow.png` 常用置顶区（E2）
- `game-dark.png` 接龙游戏（E6）

**需要你录的（核心动效，静态图替代不了）**：
1. **翻面动效**（E1 核心）：Ctrl+J 唤起 → 鼠标从左到右缓慢扫过牌阵（每张牌依次翻面）→ 悬停一张停 2 秒 → 单击启动任一程序。录 20 秒。
2. **洗牌+发牌动画**（E6/E7）：游戏模式点"新局"，录完整洗牌→发牌 8 秒。
3. **花色拖拽**（E4）：拖一张牌到花色标签上松手，录 5 秒。
4. **主题切换**（E5）：四套主题每套停 2 秒连续切换，录 12 秒。

录屏建议：OBS 1080p、关掉通知、桌面壁纸换成纯深色（牌面更突出）、鼠标移动放慢 30%。
